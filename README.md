# Credit Card - Segmentation Customer

## 🎯 Motivation

While exploring Data Science concepts, I became fascinated by how Machine Learning and data can create value and support accurate, data-driven decision-making across different industries, particularly in sectors such as Finance and Marketing.

This project provides an opportunity to apply Data Science techniques to a real-world financial dataset while gaining hands-on experience working with credit card customer data and exploring how data can be used to identify meaningful customer segments.

## 🏦 Project Description

The goal of this project is to follow the Data Science workflow to clean, transform, and analyze the dataset in order to prepare it for customer segmentation.

Using customer credit card behavior and financial information, the project aims to identify distinct customer segments that could support the development of more targeted and personalized financial services.

## 🚀 Getting started, requirements before starting
Before getting our hands dirty, make sure to have the next requirements:
- Install a Python version above 13.3.0, and the following libraries: Numpy, Seaborn, Pandas, Matplotlib, Pytorch and TensorFlow
- Download the Credit Card Customer Dataset from Kaggle
